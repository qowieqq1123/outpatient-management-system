## 已完成修改

### 1. 退出入口接入现有登出逻辑

- `frontend/index.html` 的退出按钮增加 `data-action="logout"`。
- 继续复用 `frontend/src/main.js` 中已经存在的 `logout` 点击分支。
- 浏览器 DOM 已确认该按钮现在带有 `data-action=logout`；本轮没有点击登出按钮，因此按钮的实际跳转和本地令牌清理仍需在下一次交互验收中确认。

### 2. 患者排班统一按排班状态展示

- 排班不再套用挂号单状态“已报到/已过号”。
- 增加互斥的排班展示状态：开放、已挂满、已过期、已停诊。
- 可预约号源统计排除已过期、已停诊和无余量的号源。
- 移除重复的“可预约/挂满即停”列，操作按钮与排班状态一致。
- 390px 实际页面观察到历史日期行显示“已过期”，有效开放号源计数为 1，未再出现“已报到 + 开放 + 可预约”的冲突组合。

### 3. 固定导航目标增加滚动留白

- 为页面根滚动区配置桌面、平板和手机断点的 `scroll-padding-top`。
- 浏览器在 390×844 下观察到排班面板标题顶部约为 160px，移动导航底部约为 143px，标题与固定栏之间仍有约 16px 空隙。

### 4. 收费单优先呈现应收金额和支付操作

- 收费单金额汇总和支付表单移到结算流水之前。
- 收费明细改为可展开区域，减少长明细把“确认收款/重新结算”推到页面下方的情况。
- 该部分完成代码构建；本轮没有切换收费员账号做实际浏览器画面复核。

### 5. 移动端首屏与排班表可读性

- 390px 下统计卡改为两列，并收紧卡片高度与字号。
- 移动端顶栏显示短品牌名“门诊工作台”，退出按钮保持横向单行。
- 患者排班表设定 704px 最小表宽，在面板内部横向滚动，避免日期和医生姓名被压成窄列。
- 实际浏览器状态：视口宽 390px、页面宽 390px；排班表可视宽 326px、表宽 704px，由面板内横向滚动查看后续列。
