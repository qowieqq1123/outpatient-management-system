## 3. 导出规则与 AC-25 判定

1. 图源清单由 `scripts/mermaid-diagrams.mjs` 统一提取，校验脚本与导出脚本共用，避免两处编号漂移。
2. 每张图生成一份 UTF-8 SVG 和一份 PNG；SVG 显式设置 `xmlns`、宽高、白色背景；PNG 由浏览器按 SVG 自然尺寸截图，不拉伸、不裁切。
3. 文件名使用稳定的 ASCII 序号、图号与短语，中文标题写入索引；例如 `01-PRD-01-role-usecase.svg`。
4. `docs/images/diagrams/图集索引.md` 至少记录图号、标题、源文档与行号、Mermaid 类型、SVG/PNG 路径；`docs/images/mermaid-export-report.json` 记录每张图的尺寸、字节数、源哈希与总体 `passed`。
5. `passed=true` 必须同时满足：33 张图源全部解析、33 份 SVG 与 33 份 PNG 非空、PNG 魔数正确、图号与文件名唯一、无缺失或陈旧导出文件、索引与报告写入成功。
6. 导出脚本使用本机 `scripts/mermaid.min.js` 与 Edge/Chromium CDP 9225，创建独立临时标签并在结束时关闭；不连接外部 CDN，不修改运行中的 SPA 或数据库。

## 4. 复验命令

在 `frontend/` 执行：

```bash
npm run check:mermaid
npm run check:diagrams
```

`MERMAID_CDP_PORT`、`UI_OUT_DIR` 可覆盖默认 CDP 端口和导出目录。命令应先启动带 `--remote-debugging-port=9225` 的 Edge/Chromium；不要求启动后端、前端或 MySQL，因为本次只处理本地文档图源。
